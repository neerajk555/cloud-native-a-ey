# Topic 18: Capstone Project

This is a portfolio-style final project combining every topic: Docker fundamentals, Compose, Kubernetes core objects, workloads, Helm, and real AWS deployment. Minimal hand-holding is intentional - use this as a genuine test of what you've retained, referring back to earlier topics whenever you get stuck rather than skipping ahead.

**How this topic is organized:** Local: build and fully test a small multi-service app on kind. AWS: deploy the exact same app, packaged as a Helm chart, to your EKS namespace - a real end-to-end proof of everything this course covered. Work through the local exercises fully before touching AWS -
they're free, fast to repeat, and build the exact muscle memory the AWS exercise assumes you already have.
